# 0005. On-device LLM fills a local bank, never live in the quiz

Status: Proposed (not implemented)

## Context

An on-device model could generate fresh questions. Small models are unreliable
at structured output: they wrap JSON in markdown, truncate, translate keys, or
produce valid JSON with a wrong answer. Live generation also adds latency,
heat and battery drain while a child waits.

## Decision

If generation is added, it runs in the background, writes candidates to a
pending store, and only questions that pass automatic validation reach an
approved store that the quiz reads. The quiz screen never calls a model.
Maths, geometry and logic are generated by Dart templates, not by the model.
Details and open work are in [ROADMAP](../ROADMAP.md).

## Consequences

- The app keeps working with the seed bank on any device, including ones that
  cannot run the model.
- Needs a parent-approved, Wi-Fi-only model download, so it requires a new
  network permission and a store-policy review before it ships.
- `CatalogRepository` and `ValidateQuestion` are already the integration points.
