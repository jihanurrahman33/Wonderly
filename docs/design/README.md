# Design reference

[`wonderly-all-screens.html`](wonderly-all-screens.html) is the original
design export: 23 mobile screens at 390 x 844 in a single self-contained page.
Open it in a browser to compare against the app.

It embeds the Fredoka and Nunito fonts (SIL Open Font License 1.1). The same
fonts are bundled in `assets/fonts`.

How each screen maps to code, and every intentional difference, is listed in
[`../DESIGN_MAPPING.md`](../DESIGN_MAPPING.md).
