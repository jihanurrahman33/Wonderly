## On-device question generator (phases 4 and 5)

Design principle, unchanged from the plan: **the model fills a local bank in
the background; it never writes questions live while a child plays.** Small
models are unreliable at structured output, and a wrong "correct answer" is the
worst failure for this audience.

What is already in place:

- `CatalogRepository` is the seam. A generator-backed source can sit beside
  `AssetCatalogRepository` and merge approved questions into the same
  `Catalog`.
- `ValidateQuestion` is the safety gate (distinct options, valid answer index,
  short prompt). Generated questions must pass the same function.
- Seed bank first: the app works with zero AI and zero network.
- The app declares no network permission. A model download needs an explicit
  parent-approved, Wi-Fi-only flow and a policy review before adding one.

What remains:

1. **Spike (phase 4).** Run `flutter_gemma` (or `flutter_edge_ai`) with
   Gemma 3 1B and Qwen3 0.6B on 2 to 3 real phones. Record speed, RAM and heat
   for 100 questions. Prefer `.litertlm`; skip MediaPipe `.task` for new work.
   Note LiteRT needs `minSdk 30` and arm64 only, which affects the audience.
2. **Pipeline (phase 5).**
   `topic + grade + difficulty -> prompt -> model -> raw JSON -> validator ->
   pending -> approved`. One question per call with a few-shot prompt; flat
   schema `{q, options[4], answer, fact}`; app code adds `id`, `subject`,
   `source`.
3. **Extra validation for generated content:**
   - profanity and age-appropriateness blocklist,
   - a second model pass that solves the question without the key and must
     agree,
   - maths, geometry and logic generated by Dart templates, not the model,
   - de-duplication against existing questions,
   - a "Report this question" button in the grown-ups zone,
   - manual spot-check of a sample before enabling (target 90 percent pass).
4. **Controls.** Download only after parent approval on Wi-Fi, show size,
   allow deletion, cancel on background, pause when hot or low battery, and
   fall back silently to the seed bank on weak devices.
