## [2.0.0] - 2026-11-21

### Added

- **On-device AI.** Questions are now written by a language model running on
  the phone (Qwen 2.5 1.5B or Gemma 4 E2B through LiteRT-LM), with a JSON
  schema, structure checks, a child-safety filter, duplicate detection and a
  second-pass self-check. Smart Buddy setup in the grown-ups zone: model
  choice, Wi-Fi-aware download with progress and cancel, removal, background
  generation controls.
- **Generative UI with A2UI.** A Smart Buddy card on Home and a weekly note for
  grown-ups, written by the on-device agent, validated, and rendered through
  `genui` with a deliberately tiny catalog and built-in fallbacks.
- **Numbers and Words subjects.** Numbers and Geometry and Logic are generated by
  Dart so answers are exactly right and follow the learner's grade.
- **Several learners per phone** with separate progress, a one-tap switcher and
  removal in the grown-ups zone; single-profile data migrates automatically.
- **Sound effects and music** (synthesised, bundled) honouring the settings.
- App icon and native splash screen; production README, ADRs 0005 to 0007.

### Changed

- The bundled question bank is now only a safety net.
- `INTERNET` is declared, used solely for the grown-up-approved model download.
- Android `minSdk` is 30 (LiteRT-LM); iOS deployment target is 15.
- The "Weekly report by email" toggle became an in-app weekly note (there is no
  backend to send mail).
- Dependabot now opens one grouped monthly pull request.

### Fixed

- Grade 1 subtraction could ask for numbers above 10.

## [1.0.0] - 2026-11-21

First complete build of the app from the Wonderly design reference.

### Added

- 23 screens: splash, welcome tour, profile setup, home, subjects, subject
  quiz sets, four quiz types, results with answer review, rewards, badges,
  progress, profile, parent gate, grown-ups dashboard, settings.
- Offline seed question bank (50 questions) with a validation gate.
- Stars, streaks, six badges, per-set resume and weekly progress.
- Parent gate with lockout, daily play limit that ends a session, bedtime mode.
- Read aloud (on-device text to speech), haptic feedback, text size setting.
- Clean Architecture, BLoC, `go_router`, `get_it`, `Result`-based error
  handling and global error logging.
- 140 automated tests with more than 90 percent line coverage; CI with format,
  analyze, test, coverage threshold and an Android build.
- Project documentation, ADRs, release guide and GitHub templates.

### Not included

- On-device LLM question generator (see `docs/ROADMAP.md`).
- Sound effects and music audio, email reports, multiple learners.
